# 📏 Tamanho_do_amigao_em_python – Comparador Estatístico do *“Amigão”* 😎

É um programa em Python que recebe uma medida informada pelo usuário e compara com estimativas estatísticas globais.  
Com isso, ele devolve:

- 📊 **Classificação personalizada**
- 🌍 **Comparação com a média mundial**
- 💬 **Mensagem motivacional**
- 😎 **Um toque de humor leve**

---

## 🚀 Como usar

copie o codigo e coloque em seus arquivos de programas, depois rode :
```bash
python3 tamanho_do_amigao.py
